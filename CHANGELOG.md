# Changelog

All notable public changes to SilkGuard are documented here.

## [0.1.0] — 2026-08-12

First open-source preview.

### Added

- React and FastAPI compliance-review workflow.
- Source-linked EU smart-appliance demonstration rule pack.
- Evidence-tier boundary that prevents advisory markets from running EU rules.
- Human review, remediation, retry, and incremental re-check states.
- API and deterministic-rule regression tests.
- GitHub Actions, dependency updates, secret scanning, private vulnerability reporting, and protected `main` checks.
- MIT license, contributor guidance, security policy, and third-party notices.

### Security and data boundaries

- Excluded local credentials, databases, uploads, logs, build outputs, and internal handoff material.
- Replaced unlicensed predecessor-market data with a small, newly authored example catalog.
